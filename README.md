A playground for testing [css-selector-generator](https://github.com/fczbkk/css-selector-generator) library.

## Usage

```bash
npm install
npm run dev
```

Type HTML in the left panel. CSS selectors for each element will appear in the right panel, aligned with the corresponding source lines.

## Features

- Edit HTML in the left panel
- See generated CSS selectors in the right panel
- Selectors are aligned by line number with the source HTML
- Multiple elements on one line show multiple selectors
- Multi-line elements show selector at the opening tag line
